# Verification

Run `npm test` before packaging. Tests cover physical card conservation, valid moves, tribute and exemption, review reconstruction, save failures, model-response validation, host/guest state, reconnection, four-human rooms, localization and phone hand projections.

UI acceptance covers Chinese/English switching, selection retention, real model advice, flat/fan hand layouts, phone landscape stacks and tablet rotation. Phones lock to landscape in the native app; the browser preview displays a rotation prompt in portrait. English teaching summaries use actual move data and explicitly distinguish model ranking from explanatory text. The 3D renderer and its graphics-specific tests were removed in 1.8.6.

macOS packaging includes a strict code-signature integrity check. Android packaging checks the APK signature. The `Windows package` workflow builds a ZIP on Windows, extracts it, compares bundled resources and model hashes to source, and launches the shipped EXE in Electron's Node CLI mode to check the runtime, rules, localization and portable storage. This is separate from native Windows graphical gameplay testing. Responsive browser checks do not establish performance on every phone. Tablet support shares the same Android package.

`.gitattributes` preserves upstream bundle bytes on Windows. Git's automatic CRLF conversion caused the initial provenance-hash test failure; the test remains strict and the original hashes are unchanged.

The optional `test:mac` script is an existing developer smoke harness; it uses isolated data. UI screenshots and internal reports under `test-results/` are deliberately excluded from publication.

Subtle shine starts at blue; gold adds a slow glow. Reduced-motion settings disable these effects. Short windows scroll the table independently; the bottom dock remains visible.

Selection cancellation (1.8.20): only stationary primary clicks/taps on known empty table/hand surfaces clear the selection. Validate down/move/up/click ownership, movement out and back, release-distance checks, touch scrolling, wheels, interruptions, multi-touch, modifiers, scrollbars and stale layout/selection snapshots. Escape cancels the active gesture before clearing selection, ignores repeats/IME/editable fields, and belongs to open dialogs. A cancelled held gesture suppresses its eventual click until the next physical primary press, without a timeout. Shift-click adds a displayed-order range, invalidating its anchor after a reorder, new round or externally changed selection. Tests use real hand-preparation gates; no game move is committed by selection.

Wildcard declarations (1.8.21): human previews prefer the strongest comparable interpretation. Normal plays and saved groups share an explicit declaration sheet; ambiguous commits without a key fail atomically on solo and LAN authority. Cover weaker explicit choices, sequence ends, level-rank full houses, straight-flush/bomb ordering, incomparable pair/triple runs, advice adoption, repeated confirms, stale hands/turns, and late requests after changing rooms. Verify dialog cancellation restores focus, mobile portrait shows every physical card, and landscape scrolls only the options while confirmation stays fixed. Strategy history and forced passes (1.8.22): test intact-control alternative coverage outside the model shortlist; never count a dismantled straight flush replaced by a weaker bomb as preservation. Distinguish holding the current lead from recapture: an equal external ceiling cannot be beaten by a same-rank follow-up. Retain direct finishes and urgent interceptions. History signals decay; partner-protection passes and a single pass cannot prove weakness. Verify the actual shipped worker, unchanged book-OFF results, legal deterministic candidates, and invariance to hidden-hand permutations. Preserve strategy evidence with its original action index; keep it out of active LAN projections and live review snapshots.

At 1–3 remaining cards, a larger target triggers a recorded automatic PASS for humans and bots. Test three chained passes, lead return, stale revisions, four-human rooms, pauses/disconnects and atomic rollback on save failure. In solo play, forced passes retain the user's prepared selection. Four-card hands, equal-size targets and free leads never auto-pass. Random AI waiting is 70% of its previous range (1120–1820 ms), concurrent with inference; it is not a promise that end-to-end turn latency falls by exactly 30%.
