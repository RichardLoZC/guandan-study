# 赛后统计口径（round-facts-1）

客户端使用相同统计模块。局中只有本人可见相对起手牌力；两队资源和四家起手只在本副结束后重建。普通出牌不使固定起手参考递减，贡还完成后重新固定。

- 相对牌力：原 hand-orbit-0.2.0 结构分与同级随机发牌直方图比较，显示严格低于本手的样本比例；同分不强行分出高低。比较样本为匿名的 1000 副、4000 个人起手和 2000 队伍起手。只是显示刻度转换，不证明评分预测能力提高；非胜率。参考为贡还前随机发牌，贡还后的手仍相对这个固定参考。
- 最大炸弹资源：两人各自能同时组成的最多炸弹数相加，包括同花顺和四王炸，每张实体牌只使用一次。可以拆分八张同点数为两组四张。百搭与序列重叠由精确搜索处理。正式出牌期间只有移除手牌，因此这一最大可组数量的峰值就在贡还后的起手。
- 高牌：10、J、Q、K、A、级牌、大小王的并集，占两人54张起手的比例；每张只计一次。
- 丢权：本人自由领出的小轮已结束，且下一轮由对方自由领出，记领牌者一次。该小轮有对方出炸记遇炸丢权，否则记普通丢权；同队接管不记丢权。
- 夺回：对方领出的小轮，由本人最后压住，下一轮改由本队自由领出，记一次。本人出完由队友接风，夺回记实际最后出牌者，接风记领风者。多次互压不重复计数。
- 领牌轮次/保住牌权：只数已闭合并产生下一轮先手的小轮；终局最后小轮不制造下一轮牌权。进行中的窗口不算成败。
- 拖3仍展示行动事实；起手结构比较和最大炸弹资源尚不支持此模式，显示空值。

界面不显示综合表现分、公式、待评项目或训练流程。导出保留事实和原复核数据，兼容旧技术统计导出；历史反馈不会删除。所有数据均不自动进入训练，reward=null。
