# 手牌交互设计 · 1.8.25

选牌表示“准备操作这些牌”，理牌改变位置，出牌才改变对局。三种动作使用明确的触发条件，避免把鼠标松开误判成第二次操作。

| 场景 | 操作与结果 |
| --- | --- |
| 点一张牌 | 切换这一张的选中状态，其余牌不变。 |
| Shift 点击另一张牌 | 从上一次点选的牌起，按显示顺序追加连续范围；先上排从左到右，再下排从左到右。 |
| 从空白处拖鼠标 | 向右为完整框选，向左为相交选择；Shift 追加，松手确认。 |
| 拖动已选牌 | 一起移动已选牌；成功落位后取消被移动牌的选择，保留其他选择。 |
| 拖动未选牌 | 只移动这一张，保留其他已选牌。 |
| 多选拖成一组 | 组内按牌型顺序排列；顺连按点数相邻，三带二先三张后对子。 |
| 单牌拖到已有组合牌面 | 显示“加入组合”；松手合并整个牌堆，重新识别并更新名称。 |
| 单牌拖到组合间隙 | 保持独立牌，不因靠近组合就自动并入。 |
| 轻点牌桌或手牌区空白 | 取消选择，保持牌序和分组。 |
| 触屏划过空白 | 滚动手牌，保留选择。 |
| 按 Esc | 有弹窗时由弹窗处理；否则先取消拖动／框选并保留原选择，再按一次清空选择。 |
| 切换平铺／弧形 | 保留牌序、分组和选择。 |
| 理下排或切换理牌优先方式 | 只在下排寻找组合并轮换方案；上排保留牌序、分组和位置。 |
| 按大小 | 只将下排恢复为点数排序，上排保持不变。 |
| 理牌或换一副 | 连选起点失效，下一次点击重新确定起点。 |

## 手机单区叠牌

手机固定横屏；同点数按列叠放，每列最多三张，更多同点数牌拆为相邻列。每张牌的露出条显示点数、花色及级牌星号，红桃级牌标“配”。点击露出条选牌；拖动调整单区中的牌序。旧双排存档合并到单区，保留实体牌 ID、原有组合和组内顺序。

手机“理牌”和“按大小”作用于整手牌；Mac、Windows、Pad 的上排保留／下排试排规则继续有效。组合分隔、单牌并组、歧义声明和撤销共用原有逻辑。手机不提供跨排拖动，也不接受 Alt+上／下将牌移入隐藏排。组合过多时横向滚动，保留可点的牌头宽度。

## 交互边界

- 空白取消在完整的按下、松开、点击后生效。移动达到 6 个 CSS 像素便不再视为轻点；移出去又移回来也算拖动。
- 两次点击之间的 AI 行动不清空预选；本机手牌、布局或选择已改变时，旧的空白按压不能清空新选择。
- 取消拖动后，即使继续按住很久，松开也不会产生一次选牌。下一次真实按下立即恢复响应。
- 工具按钮、牌面、玩家资料、桌面已出牌、滚动条和弹窗内容都不属于空白区域。
- 滚动、失焦、多点触控、窗口变化会使待完成的空白点击失效。输入框、下拉框、输入法和长按重复按键保留自身行为。
- 选牌与理牌不提交任何对局动作；只有明确的出牌、打出组合、不出或贡还确认按钮才提交。
- 合并后若整堆不是合法牌型，保留所有牌并清除旧牌型名称。若移走部分牌，来源组合也重新识别；撤销会一起恢复原牌序和分组。
- 弧形布局以实际可见的目标牌面判断并入哪组，避免末端上层牌被下层的矩形区域误接收。多人一起拖放始终创建独立组合，不吞并经过的其他牌堆。
- 上排是玩家的保留区；自动理牌不借用上排的牌凑组合。跨排拖动后，旧的下排方案立即失效。下排为空时停用自动理牌与按大小，仍可手动将上排牌移回来。
- 两排独立计算横向间距，并预留滚动条空间，避免下排组合数量改变时压缩或移动上排。新到手的贡还牌加入下排；撤销保留原有作用范围，出牌仍正常移除已打出的牌。

## 界面反馈

保持现有选牌抬起、勾选和数量反馈，不增加浮层或工具栏。取消操作通过牌面回位与“取消选择”按钮禁用反馈。手牌区悬停说明解释 Shift 连选与空白取消；拖动中显示“松手放下 · Esc 取消移动”。

暂不加入双击直接出牌、拖向牌桌出牌、空格确认出牌。这些手势容易与点选、理牌或键盘浏览冲突。将来若加入，应作为玩家主动开启的偏好，并经过触屏与鼠标误触验证。

## 逢人配声明

可比较的解释按牌力从大到小排列，预览默认显示较大的解释。点击「声明出牌」或有歧义的「打出组合」会在窗口底部打开声明面板，列出合法牌型和每张逢人配补成的牌；点击「确认出牌」才提交。取消或按 Esc 保留选牌与分组，焦点回到原入口。没有歧义时仍一键出牌。

连对与钢板等不同普通牌型不能互相比较，面板明确提示这一点，只在同牌型内标记较强的解释。三带二的大小以三张部分判断，附带对子不参与比大小。只显示当前能压过桌面牌的解释。

单机与联机都要求有歧义的出牌带明确牌型。确认时重新校验牌局、回合、手牌和解释；旧牌局、失联、重复确认及迟到网络响应不会替代当前声明。DanLM 仍使用模型选定的明确牌型，不应用人的默认排序。

## 验收

核心边界由 `hand-selection`、`hand-editor`、`hand-marquee` 和 `hand-preparation` 测试覆盖。界面验收使用独立测试牌局，检查平铺／弧形、跨上下排、关闭弹窗、长时间按住后取消、窄屏触摸滚动，以及中英文提示。真实用户的牌局不用于试出牌。
