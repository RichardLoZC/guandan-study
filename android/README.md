# 掼蛋研习社 · Android 手机与平板版

与桌面版共用项目中的 `web/`：规则、DanLM 权重、机器人、三套牌面、教学、终局明牌与复盘。平板主要验证设备为 Xiaomi Pad 7 Ultra（Android 16，3200×2136）；手机使用同一安装包。1.8.15 已安装到 Xiaomi 15 Pro，针对其 1440×3200 屏幕适配横竖屏。

平板界面在 `android/web/`，只在 Android 打包时加入。手机布局在 `web/app/phone-layout.css`，仅对 Android 小屏生效：竖屏上下分区，横屏牌桌在左、手牌在右。出牌／不出固定在底栏，理牌工具可横向滑动；手牌下方有独立滑动区，可看全手牌而不误触理牌。长牌型和终局余牌按需要换行，牌桌区可独立滚动。支持平铺与弧形两种 2D 手牌布局、双层自由理牌、中英文、大字和夜色。点击选牌，按住拖动即移动牌序；多选后可整组移动。系统返回优先取消拖动、关闭面板、清除选牌，再返回桌面；切入后台会暂停模型任务，旋转保留牌局。

进贡、还贡和抗贡会在牌桌直接亮牌，显示判定原因、牌面、流向和当前操作人。双贡收齐后才确定收贡对象；贡还或抗贡完成后等待用户点击「开始出牌」，无自动跳过。正式出牌后，牌桌顶部保留本副贡还摘要；退出重进仍保留确认状态。

顶部「单人练习 → 重新开始」可重新洗牌发牌、双方从 2 开始并重置到第 1 副。确认后替换当前牌局，保留已完成的历史复盘；取消则继续当前牌局。重开前自动保留一份当前牌局备份。

单局结束页会单独展示最后打出的牌，包含出牌玩家、名次、牌型和完整牌面，放在剩余手牌明示之前。复盘总览及文字导出同步保留该信息；以前完成的历史牌局也从真实行动记录还原最后一手。开始下一副会清空这块结束信息。

单人／多人共用模式入口，外观和暂停放在设置。房间直接展示四个座位，支持 2—4 位真人；四人坐满时所有行动由玩家决定。加入后等待房主开局，各设备自动进入牌桌。可返回原来的单人进度，联机与单人分别保存。

牌桌为每名玩家保留本轮最近一次出牌或 PASS，出牌与手牌使用同一尺寸，最新出牌以专属色边框突出；下一轮领出时清空。联机结算和复盘按本机视角显示。AI 还贡使用独立的手牌结构策略，正常出牌仍由 DanLM 决策。

## 安装与使用

将发布目录中的 APK 发送到手机或平板，在文件管理器中打开并按系统提示安装。安装完成后从桌面打开“掼蛋研习社”。单机存档各自保留；联机时点顶部模式入口 → 多人游戏，自动选中附近牌桌，输入六位房间码即可加入。未找到牌桌时可展开手动地址输入。

单机内置模型，无需电脑、USB 或网络。联机由 Mac 或 Windows 房主运行 DanLM，需处于同一可信局域网。Android 包声明 INTERNET，用于本地网络房间；不申请通讯录、相册或整个存储空间权限。导出存档与复盘时，系统文件选择器让用户选择保存位置。卸载应用会清除本机牌局，卸载前请先导出；更新同一签名的 APK 可保留数据。

最低 Android 8；需要 Android System WebView 120 或更新版本。旧 WebView 会显示更新提示。横屏更适合完整牌桌；竖屏和分屏也有布局适配。完整测试范围与真机安装结果见发布目录的验证说明。

## 构建

需要 Node.js、JDK 17、Gradle 8.13、Android SDK Platform 36 和 Build Tools 36.0.0。在项目根目录执行：

```sh
node --test test/*.test.cjs
node scripts/build-android.mjs
```

若当前机器已有完整依赖缓存，可加 `--offline`。`--debug` 生成单独包名 `com.guandan.study.dev` 的测试版，正式版包名是 `com.guandan.study`。正式版关闭 WebView 调试。

`ANDROID_HOME`、`JAVA_HOME` 和 `GUANDAN_GRADLE` 可指定 SDK、JDK 和 Gradle 可执行文件。Mac 默认使用用户的 Android SDK、Homebrew OpenJDK 17 与 Gradle 8.13 缓存。构建在本机临时目录进行，APK、SHA-256 与构建信息输出到项目 `dist/GuandanStudy-Android/`。

首次正式构建在本机 `~/.local/share/guandan-study/` 生成应用签名密钥与密码文件（权限仅限当前用户），不会放入 NAS 项目或安装包。后续构建必须保留该密钥，才能覆盖更新已有安装。也可通过 `GUANDAN_STORE_FILE`、`GUANDAN_STORE_PASSWORD` 指定外部密钥，别名固定为 `guandan`。发布目录不包含私钥。

## 原生入口

- `MainActivity.java`：WebView、窗口安全边距、系统返回、前后台生命周期及系统文件保存器。
- `LocalAssets.java`：把包内资源提供为同源 HTTPS URL，检查主机、方法和路径；资源缺失时返回错误，不回退到网络。
- `web/pad.js`：原生导出与生命周期衔接；拖动手势使用共享手牌编辑器。
- `web/pad.css`：平板专用布局，保留 macOS 已确认的桌布、牌面和玩家颜色。

使用本地 HTTPS 原点是为了让模块 Worker 和模型资源遵守同源规则，做法参考 [Android 的应用内内容加载说明](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)。窗口适配同时考虑 [Android 16 大屏行为](https://developer.android.com/about/versions/16/behavior-changes-16#adaptive-layouts)。

模型及素材沿用原许可，DanLM 含非商业条件；许可文件保留在应用“设置 → 规则与说明”和包内 `mobile/`、`card-sources/`。

`LanTransport.java` 只接受局域网 IPv4 和固定 JSON API，拒绝 HTTP 重定向；WebView 只载入本地资源，保持混合内容禁止。网络 HTTP 未提供 TLS，只支持可信局域网。

## 自由理牌

每副牌初始全部按大小放在下排，上排留空。平铺和弧形共用本机牌序，直接拖动单张或已选组合跨排换位，松手完成；可撤销上一次移动。出牌及贡还只增减对应实体牌，重新打开同一副可恢复。拖动期间停用出牌按钮；窄屏手牌可左右滚动，拖到边缘会自动滚动。「理牌」按钮自动寻找并轮换组合。
