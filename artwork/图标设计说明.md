# 掼蛋研习社图标：对家

2026-10-12，用户从五个设计方向中选定第 2 款「对家」。四个牌形人物围成一桌，象牙白与暖金色交错，四种花色和中心红色菱形表达对家协作。深绿底与牌桌配色一致。

原方案和透明背景处理均使用内置 `image_gen`，没有使用 CLI。正式母版为 `app-icon.png`（1254 × 1254，圆角外保留真实透明通道）。原方案保存在 `logo-options-2026-10-12/02-partners.png`。不包含用户参考照片。

`node scripts/build-icons.mjs` 仅做尺寸和格式导出：

- `build/icon.icns`：macOS，16–1024 像素。
- `build/icon.ico`：Windows，16、24、32、48、64、128、256 像素。
- `icon.png`：桌面窗口，256 像素。
- `web/assets/brand/app-icon.png`：应用页眉、网页图标及 GitHub README，128 像素。
- `android/app/src/main/res/mipmap-*/ic_launcher.png`：Android mdpi 至 xxxhdpi，48–192 像素。
