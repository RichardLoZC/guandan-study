# 掼蛋研习社 Logo 方向

由内置 image_gen 工具分别生成，共五款。用户已选定第 2 款「对家」，正式透明母版见上一级 `app-icon.png`；生成和平台导出记录见 `../图标设计说明.md`。

1. **扇牌**：熟悉的握牌轮廓，偏经典牌社气质。 `01-fan.png`
2. **对家**：四个座位围成一桌，突出搭档与联机。 `02-partners.png`
3. **掼印**：朱红印章与“掼”字，偏中式文化气质。 `03-seal.png`
4. **牌序 G**：将卡牌折角融入 G，简洁、易于缩小。 `04-monogram.png`
5. **牌友**：扑克牌化作猫头鹰，呼应策略与学习。 `05-mascot.png`

完整生成提示词见 prompts.json。对比页见 index.html。
