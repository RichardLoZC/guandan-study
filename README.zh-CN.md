## 项目介绍

支持 macOS、Windows、安卓手机和平板的掼蛋应用。可离线与 DanLM 对局，也可在同一局域网内与朋友一起玩。牌桌顶部点击 **English / 中文** 即可切换语言，当前牌局和选牌保留。

**内置 DanLM 模型仅限非商业用途。** 公开仓库不代表所有组件都可无限制商用，详见[许可与素材来源](THIRD_PARTY_NOTICES.md)。

## 功能

- 2D 牌桌，手牌可选平铺或弧形握牌；三套牌面、日夜主题和大字模式。
- 一键理牌，搜索整手牌可同时保留的组合，考虑不同花色与逢人配分配，轮换展示多种方案。
- 单人练习，模型建议、教学、整局复盘、逐手回放与导出。
- 设置中可独立开关秘籍对 AI 出牌及教学建议的影响；自动保存选择，联机由房主统一设置。
- 桌面显示进贡、还贡、抗贡；各家保留本轮最近一次出牌或 PASS；终局显示最后出牌和剩余手牌。
- AI 每手保留随机 1.6～2.6 秒的观察时间，模型同时计算；当前玩家的头像和状态高亮，区分“思考中”和真人“正在出牌”。
- 同一 Wi-Fi 内 2～4 位真人联机，空位由 DanLM 补齐；四人可全部是真人。
- 电脑开桌，其他电脑、手机、平板自动找桌并输入六位房间码加入。新游戏或破 A 后重新随机分位。
- 安卓横竖屏适配，牌局自动保存在各自设备，无需账号或在线模型服务。

## 安装与使用

从 [Releases](https://github.com/RichardLoZC/guandan-study/releases) 下载对应文件。

- **Mac：** 解压 Universal ZIP，将 `掼蛋研习社.app` 放入“应用程序”。支持 Apple 芯片和 Intel。
- **Windows：** 解压完整 ZIP，运行 `GuandanStudy.exe`，无需安装到系统目录。提供 x64 版本。
- **安卓：** 安装 APK，手机和平板共用一个安装包。需要 Android 8 或更新系统，以及 WebView 120 或更新组件。同包名、同签名可覆盖更新。

Mac 使用本地 ad-hoc 签名，未公证；Windows 未使用 Authenticode 证书签名。安卓使用独立发布密钥。

点击“单人练习”打开模式面板，再选“多人游戏”。一台 Mac 或 Windows 电脑“开一桌”，其他设备选择附近牌桌并输入房间码。安卓当前作为加入端。房主保持开机；如 Wi-Fi 禁止设备互访，自动发现和手动连接都可能失败。

## 模型与语言

DanLM ONNX 权重负责出牌候选行动评分，规则层验证合法性，可选秘籍策略辅助选择。中英文、不同手牌布局和不同设备共用同一套权重，没有重新训练模型。在 **设置 → AI 出牌策略** 中关闭「秘籍影响 AI 出牌」，AI 将使用 DanLM 原始评分，从下一次出牌生效；教学建议和还贡策略不受此开关影响。联机时只有房主能修改，所有玩家同步查看同一设置。

AI 还贡采用独立的手牌结构策略，只使用自己的手牌、级牌和合法候选。比较还牌后可保留的组合，减少拆开炸弹、同花顺、对子和顺连的损失，结构相近时优先还较低点数的牌。这是有界启发式策略，不是 DanLM 对还贡的模型推理，也不保证全局最优。

讲解来自教学层。英文讲解显示推荐行动、余牌、候选分数及公开信息范围；不是模型的内部思考，分数不代表胜率。语言切换不改规则、模型输入或存档内容。旧拖 3 存档保持兼容，新游戏不再提供拖 3。

## 自由理牌

Mac 和 Windows 窗口缩小时会按完整牌桌等比例缩放；头像、出牌、手牌和按钮保持原有比例。菜单「显示 → 恢复大小」可重新适应当前窗口。

点一下选牌，按住拖动就立即理牌，没有等待时间；轻微抖动不会触发，松手完成。先选中多张牌，再拖动其中一张，就会整组移动。金色线条显示落点，「撤销理牌」恢复上一次手动或自动调整。鼠标、触屏和笔使用同一套操作；划过牌面也用于移动，多选时逐张点选。

对手或 AI 出牌、暂停、等待联机回包时，都可以先选牌和理牌；只有轮到自己且符合规则时才能确认出牌。发牌动画和本副结束时停止手牌操作。上下两排始终预留同样的空间，上排从空变为有牌时，手牌区域不会增高，牌桌和底栏也不会移动。

自动理牌会比较整手牌的多种拆分方式，包括用逢人配补同花顺、保住另一组炸弹等相互影响的组合。搜索有计算量上限，提供可轮换的方案，不保证全局最优。

每副牌初始全部按大小放在下排，上排留空放组合；已手动或自动理过的牌序会保留。平铺和弧形均保留双层手牌，切换布局保留已选牌和牌序；窄屏可在手牌区空白处左右滚动。键盘聚焦手牌后，直接用 Alt / Option + 方向键移动当前牌或选中的组合。出牌不会重排其余牌，重新打开同一副会恢复，下一副重新排列。「不出／出牌」固定在底栏醒目位置，布局切换和理牌工具集中在一起；「看建议」教学入口与出牌记录位于右下方。选择「同花顺优先」「炸弹优先」「顺连优先」或「对子优先」会立即寻找组合；继续点「理牌」轮换方案。「按大小」恢复到下排排序，可用「撤销理牌」撤回。手牌显示顺序不改变规则、DanLM 输入或模型权重。

## 开发

```sh
npm ci
npm test
npm start
npm run build:mac
npm run build:win
npm run build:android
```

需要 Node.js 22.12+；安卓另需 JDK 17、Gradle 8.13、Android SDK 36 和 Build Tools 36.0.0。详细环境变量见[构建说明](docs/BUILDING.md)。首次开发构建需要下载依赖，安装后的游戏可离线运行。

Mac 存档位于 `~/Library/Application Support/GuandanStudyOffline`。Windows 默认位于 EXE 旁的“掼蛋数据”，目录不可写时使用 `%APPDATA%/GuandanStudyOffline`。安卓保存在应用私有目录。卸载前请先导出备份。

联机只面向可信局域网，采用 HTTP/UDP，房间码不提供加密。不要将房主端口映射到互联网。

本项目基于严锋教授原项目的 Windows 1.0.0 离线包改编，原包没有提供 React/TypeScript 源码。本项目保留压缩代码及提取哈希供核对，并重写了可维护的界面、状态管理、联机与跨平台入口。原包所附的 Copyright 2026 shef-wang 声明，以及 DanLM、纸牌素材许可均按原样保留。本项目不代表 DanLM 官方。
